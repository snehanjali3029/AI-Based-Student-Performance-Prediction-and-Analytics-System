# Roadmap and acceptance checks (proposal page 11)

1. Foundation: repository, data dictionary, baseline model, data quality.
2. Prediction: model comparison, cross-validation, holdout testing, SHAP explanation support.
3. Risk monitoring: configurable thresholds, risk dashboard, explanations.
4. Student/faculty UI: role pages, subject analytics, what-if simulator.
5. Data/database: CSV/XLSX import, validation, SQL persistence.
6. Recommendations/reports: study planner, PDF report, faculty intervention workflow.
7. Quality/release: access control tests, test suite, documentation, deployment.

Predictions are estimates. Review risk thresholds, model errors, false alarms, data consent and access control with the institution before real use.
